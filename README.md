# 🌱 Botânica Divertida

Jogo educativo de Botânica para alunos do 7º ano — todo em português brasileiro.

## Como jogar

Abra o arquivo `index.html` em qualquer navegador moderno (celular ou computador).
Não precisa de internet nem de instalação: é um único arquivo HTML autossuficiente.

Ou jogue online pelo GitHub Pages (após ativar nas configurações do repositório):
`https://<seu-usuario>.github.io/jogo-botanica/`

## Atividades

1. 🌿 **Explorar as partes da planta** — raiz, caule, folha, flor, fruto e semente, com fotos reais
2. 🧩 **Monte a planta** — toque no nome e depois no lugar certo da planta
3. 🔄 **Ciclo de vida** — da semente ao fruto, etapa por etapa
4. ☀️ **Fotossíntese** — simulador interativo com controles de luz, água e CO₂
5. 🔤 **Adivinhe a palavra** — jogo da forca com 8 palavras da botânica
6. 🎯 **Quiz** — 2 níveis (Fácil e Médio), 20 perguntas cada, com ilustrações, fotos reais e ranking

## Detalhes técnicos

- Arquivo único (`index.html`), sem dependências externas
- Fotos reais embutidas no próprio arquivo + ilustrações SVG desenhadas à mão
- Sons gerados com Web Audio API (sem arquivos de áudio)
- Ranking do quiz salvo no navegador (localStorage)
- Layout responsivo para celular e computador
